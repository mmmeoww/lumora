## Сравнение размещения

Сайт полностью статический (HTML/CSS/JS), поэтому серверный хостинг не нужен.

| Критерий | GitHub Pages (рекомендуется) | Cloudflare Pages / Netlify | VPS (nginx) |
|---|---|---|---|
| Статический сайт | да | да | да |
| Node.js / БД / CMS | нет | ограниченно (функции) | да |
| HTTPS | автоматически, в том числе для своего домена | автоматически | настраивается вручную |
| Деплой | через GitHub Actions (готов в репозитории) | из Git | вручную / CI |
| Резервные копии | история Git | история Git | нужно настраивать |
| Сложность | минимальная | низкая | высокая |
| Доступность в РФ | работает, но возможны перебои из-за ограничений сети | аналогично | зависит от провайдера |

**Рекомендация:** GitHub Pages: достаточно для текущего проекта, деплой уже настроен. **Альтернатива:** Cloudflare Pages/Netlify. **VPS** нужен только если появятся база данных, оплата и админка (см. `03-tz.md`, раздел «Этап 2»).

Цены не указаны сознательно: тарифы и условия бесплатных планов меняются, их нужно сверять на сайтах провайдеров на момент покупки. Что проверить: лимиты трафика/сборок, возможность привязки своего домена, доступность для целевой аудитории.

## Нужные сервисы

- Регистратор домена (платно, владелец).
- Приём форм (Formspree или аналог): нужен, иначе заявки не отправляются.
- Яндекс Вебмастер и Метрика (бесплатно, аккаунт владельца).

## План публикации

| № | Шаг | Кто |
|---|---|---|
| 1 | Создать репозиторий на GitHub, залить код | разработчик |
| 2 | Settings → Pages → Source: **GitHub Actions** | разработчик |
| 3 | Первый деплой (push в `main`), открыть `https://<user>.github.io/<repo>/` | разработчик |
| 4 | Зарегистрировать домен | **владелец** |
| 5 | Settings → Pages → Custom domain, дождаться HTTPS | разработчик + владелец |
| 6 | DNS у регистратора: A-записи на IP GitHub Pages либо CNAME на `<user>.github.io` (актуальные значения смотрите в документации GitHub) | **владелец** |
| 7 | Включить Enforce HTTPS | разработчик |
| 8 | Завести приём форм, прописать `FORM_ENDPOINT`, `CONTACT_EMAIL` в Variables | **владелец** предоставляет, разработчик настраивает |
| 9 | Создать счётчик Метрики, прописать `METRIKA_ID` | **владелец** |
| 10 | Вебмастер: подтвердить права, отправить sitemap | **владелец** (см. `06-launch.md`) |
| 11 | Проверить страницы, формы, мобильную версию | разработчик |

**Не выполнено:** шаги 1–11. Публикация не проводилась.
