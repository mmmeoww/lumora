# 6. Публикация, Яндекс Вебмастер и Метрика, готовность

## Яндекс Вебмастер (действия владельца)

1. Откройте webmaster.yandex.ru → «Добавить сайт» → введите адрес (с https://).
2. Выберите подтверждение через **мета-тег**. Скопируйте значение `content`.
3. На GitHub: Settings → Secrets and variables → Actions → Variables → `YANDEX_VERIFICATION` = это значение. Запустите деплой (push или Run workflow).
4. В Вебмастере нажмите «Проверить».
5. «Индексирование» → «Файлы Sitemap» → добавьте `https://<домен>/sitemap.xml`.
6. «Диагностика» и «Статистика обхода»: исправьте найденные ошибки.
7. Для адреса вида `<user>.github.io/<repo>` подтверждение и индексация неудобны (общий домен). Для продвижения лучше подключить собственный домен.

## Яндекс Метрика (действия владельца)

1. metrika.yandex.ru → «Добавить счётчик» → адрес сайта. Вебвизор можно не включать.
2. Скопируйте номер счётчика.
3. GitHub → Variables → `METRIKA_ID` = номер. Деплой.
4. На сайте появится баннер cookies; после «Разрешить» загружается счётчик.
5. Метрика → «Цели» → создать цели типа «JavaScript-событие» с идентификаторами из `04-traffic-map.md`.
6. Проверка: откройте сайт, примите cookies, в Метрике смотрите «Отчёты → Мониторинг → В реальном времени» и срабатывание целей. **Пока не проверено**, счётчика нет.

## Приём форм (обязательно перед запуском)

Без этого заявки не уходят. Вариант: Formspree (или аналог): создайте форму, укажите email получателя, получите URL вида `https://formspree.io/f/xxxx`. Запишите его в Variables как `FORM_ENDPOINT`, а публичную почту: `CONTACT_EMAIL`. Сайт отправляет JSON методом POST. Если выбираете другой сервис, проверьте, что он принимает JSON и разрешает CORS с вашего домена. Доставку писем проверьте тестовой заявкой.
