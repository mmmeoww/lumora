## Внутренняя перелинковка (реализована)

- Статья → «Как это работает», каталог, создание, связанные статьи (в тексте и блоком «Читайте также»).
- Видео → статья и приключение, `create/`.
- Приключение → «Похожие», `create/`.
- FAQ → страницы по теме (ссылка в каждом ответе).
- Главная → все ключевые разделы. Хлебные крошки везде.
- `scripts/check.mjs` контролирует битые ссылки и страницы без входящих.

URL: латиница (транслит), нижний регистр, слэш на конце, без параметров.
